# GitHub Copilot Chat Modes Adapter

Drop-in chat mode definitions for GitHub Copilot in VS Code.

## Installation

1. Copy `.github/chatmodes/` into your project's `.github/` folder:
   ```bash
   cp -r adapters/copilot/.github ./
   ```
2. In VS Code GitHub Copilot Chat, access the modes via the participant/mode picker:
   - Select **Adaptive Teacher** for guided skill retention and scaffolding.
   - Select **Blast-Radius Critic** before writing migrations or sensitive changes.
   - Select **Sparring Teammate** for architectural option matrices.
