# Roo Code Adapter: Cognitive Personas

Drop-in `.roomodes` configuration for Roo Code (VS Code extension).

## Installation

1. Copy `.roomodes` into your project root:
   ```bash
   cp adapters/roo-code/.roomodes ./
   ```
2. In the Roo Code interface, open the mode selector dropdown:
   - Select **Adaptive Teacher** for guided scaffolding and skill acquisition.
   - Select **Blast-Radius Critic** (hardware-enforced read-only) before running migrations or critical architectural changes.
   - Select **Sparring Teammate** for trade-off exploration and architecture decision matrices.
